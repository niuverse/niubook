## 2. 生成流水线

### 可考的痕迹

- `references.bib` 头部写明：由 **R1–R7 七份研究简报**合并，按引用键 / arXiv ID / 规范化标题去重。
- `AUTHORING.md`（原包内）面向「所有章节 writer」，规定了统一符号、定理环境、CeTZ 图表规范与引用纪律。
- `bibkeys.txt` 是一份 327 条的**文献预分配清单**——写作前把可用 key 发给章节作者，从机制上压制虚构引用。
- 17 个章节文件的归档时间集中在 2026-10-22 的 13:19–16:18，呈现并行写作后统一收口的形态。

### 生成模型

- 初稿生成：**Kimi K3**（Moonshot AI），由作者确认。
- 人类作者完成：选题、大纲设计、多轮编辑、引用核验、统稿与版式定稿。

### 不可考的部分

以下信息没有随归档保留，本文件不作推测：

- 每章使用的具体模型版本/快照与采样参数；
- 章节级 prompt 与对话记录；
- R1–R7 简报原文；
- 每章的执笔 agent 身份与生成顺序。

若未来需要更强的可审计性，`docs/PRODUCTION.md` 规定了新书必须留存的记录项。
