# 图形规范

图的目标不是"信息多"，而是**在 100% 页宽下可读**：文字不出框、线不穿字、
标签不互相覆盖、箭头有线杆。以下规则来自 v1.0.2 对全书 22 幅 CeTZ 图的返修。

## 1. 画布与字号

- 画布宽度不超过 **15.5 cm**（正文宽约 16.2 cm），超出会被页边裁切。
- 节点内文字 **7–8 pt**，注释/图例 **6.5–7 pt**；低于 6.5 pt 在纸质打印上不可读。
- 画布高度不限，但一张图不应独占整页；超过 12 cm 时考虑拆成两幅。

## 2. 盒子与文字

最常见的故障是**文字比盒子宽/高**。排版前先算：

```text
可用宽度 ≈ 盒宽 - 2 × 内边距(0.15cm)
一行汉字数 ≈ 可用宽度 / (字号 × 0.035cm)
```

- 一个盒子最多 **3 行**；超过就拆盒或删字。
- 不要靠 `content` 自动换行——CeTZ 不会按盒子宽度换行，文字会溢到框外。
  需要换行时显式写 `\`，或用 `block(width: 5.2cm)[...]` 限制宽度。
- 同一行的盒子要有 **≥ 0.25 cm** 间隙；上下两排盒子之间留 **≥ 0.6 cm** 给箭头和标签。
- 分类树/层级图的同类盒子必须等高；每格文字统一 3 行，避免一行高一行矮。

## 3. 箭头

- 箭头必须**从节点边界起止**，不要在节点中心之间直连后再"希望"节点盖住线头。
- 裁剪距离 `off = 节点半宽 + 0.12cm`。若两节点中心距 `< 2 × off + 0.5cm`，
  线杆会被裁没——先缩小节点或加大半径，不要只改箭头。
- 线杆长度至少是箭头头部的 **2 倍**；否则看起来只有箭头尖。
- 双向关系用 `mark: (start: ">", end: ">")`，不要画两条重叠的线。

## 4. 标签与虚线

- 标签压在线上时，必须加白底：
  `content(..., frame: "rect", fill: white, stroke: none, padding: 1.2pt, ...)`。
- 失败/回流虚线不要穿过任何节点或标签；在两排盒子之间留一条**专用走线带**，
  或从底排下方绕行。
- 多条失败路径汇合时，画一条总线 + 一个概括标签（如「失败 → 修订 / 拒绝 / 回滚」），
  不要为每条路径各放一个长标签——那必然互相重叠。

## 5. 时间线与密集事件

- 同一季度超过 **3 个**事件时，不要在轴上逐个贴名字；保留散点，
  在轴下方用一行分组说明（`2026 H2：A · B · C · D`）。
- 轴末端的 `2026.10` 之类标签放在轴内（`anchor: "east"`），不要伸出画布。
- 泳道名放左侧固定列，事件标签最多两行，避免跨泳道。

## 6. 分层图

- 每层用「粗体主标签 + 次级细节」两行，主标签 ≤ 28 个汉字，细节 ≤ 32 个字符。
- 层高 ≥ 1.4 cm；两层之间 ≥ 0.4 cm，给上行/下行箭头留空间。
- 侧挂的"真实世界/外部系统"盒子宽度 ≥ 2.8 cm，文字最多 3 行。

## 7. 验收流程

每次改图后：

```sh
just build
pdftoppm -f <page> -l <page> -r 150 -png dist/books/<slug>/<slug>.pdf /tmp/fig
```

1. 先看 100% 页面：图是否超出正文宽、是否压到页边。
2. 再看 300 dpi 局部：文字是否出框、箭头是否有杆、标签是否互压。
3. 跑 `just check`，确认页数基线（`stats.pages`）与文本指纹。
4. 用 PyMuPDF 做一次字形扫描，确认没有 `.notdef`（缺字豆腐块）：

```sh
uv run --with pymupdf python - <<'PY'
import pymupdf
doc = pymupdf.open("dist/books/embodied-rsi/embodied-rsi.pdf")
bad = sum(1 for p in doc for s in p.get_texttrace()
          for c in s.get("chars", []) if c[1] == 0)
print("pages", len(doc), "notdef", bad)
PY
```

## 8. 提交前检查清单

- [ ] 画布宽度 ≤ 15.5 cm，未压页边
- [ ] 所有盒子文字 ≤ 3 行，且不出框
- [ ] 每条箭头都有可见线杆，起止在节点边界
- [ ] 虚线不穿过节点；跨线标签有白底
- [ ] 同一区域没有两个标签重叠
- [ ] 页数与 `stats.pages` 一致，文本指纹已更新
- [ ] PDF 中 `.notdef` 为 0
