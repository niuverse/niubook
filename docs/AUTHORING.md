# 系列写作规范

适用于 `books/` 下的所有书。单本书可在自己的 `AUTHORING.md` 中追加更严格的规则；
两者冲突时，以**更具体的那份**为准，并在该书中说明差异。

## 1. 文件与导入

- 每章一个文件 `chapters/chNN.typ`，编号连续，两位数字。
- 章节首行（允许前置注释）：

```typst
#import "../template.typ": *
```

- 标题层级：章 `= 标题`（显示为「第 N 章」），节 `==`（N.M），小节 `===`。
- 正文只依赖 `template.typ` 导出的组件，不要绕过它直接 import 工具链内部文件。

## 2. 数学

- 行内 `$...$`，行间 `$ ... $`；需要引用时加标签 `$...$ <eq:xxx>`，用 `@eq:xxx` 引用。
- 公式按章自动编号 (N.k)。
- 全书统一符号（新书必须在开写前确定并写进附录符号表）：

| 记号 | 含义 |
| --- | --- |
| $s in cal(S)$ / $a in cal(A)$ / $o in cal(O)$ | 状态、动作、观测 |
| $P(s'|s,a)$ / $r(s,a)$ / $gamma in [0,1]$ | 转移、奖励、折扣 |
| $pi_theta (a|s)$ / $theta$ | 策略与参数 |
| $tau = (s_0,a_0,r_0,...)$ / $J(theta)$ | 轨迹与回报 |
| $cal(H)$ / $cal(A)_"llm"$ | Harness 与 Agent |
| $Phi$ / $m$ / $cal(D)_"val"$ | 改进算子、修改、验证集 |

- 期望用 `EE`，概率用 `PP`（模板已定义）。
- 长推导用 `\` 分行，按等号对齐。

## 3. 定理环境

模板提供：`definition` `theorem` `lemma` `proposition` `corollary`
`assumption` `remark` `example` `proof` `keybox`。

```typst
#definition(title: [Harness])[...]
#theorem(title: [收敛性])[...]
#proof[...]
#keybox(title: [本章要点])[...]
```

- 定理编号按章重置，不需要手工编号。
- 「定义」给严格表述，「注记」放直觉、边界与反例，两者不要混写。

## 4. 图

- 矢量图用 CeTZ，每章 2–4 幅；统一写法：

```typst
#import "@preview/cetz:0.3.4"

#figure(
  cetz.canvas(length: 1cm, {
    import cetz.draw: *
    // ...
  }),
  caption: [图题],
) <fig:xxx>
```

- 配色只用模板 token：accent `#0f5c5c`、accent2 `#8c5a2b`、softbg `#f6f4ef`、
  softline `#d9d4c8`。
- 画布宽度不超过 15cm，节点内字号 7.5–8pt。
- 图必须承载信息（架构、数据流、时序、算法），禁止装饰性图片。
- 每幅图都要在正文中被 `@fig:xxx` 引用并解释。

## 5. 表

- 用 `#figure(table(...), caption: [...])` 包裹，表头自动加粗。
- 对比表的列名要短；窄列禁止两端对齐（模板已全局关闭）。
- 表格与图一样需要正文引用。

## 6. 引用

- **只引用 `bibkeys.txt` 中分配给本章的 key**。这是硬约束，不是建议。
- 需要新文献时，必须真实存在且可核查（arXiv / DOI），在章节末尾申报：

```typst
// NEWBIB: key = 标题, 作者, 年份, arXiv:XXXX.XXXXX
```

由主编统一入库后才能使用。
- 引用写法 `@key` 或 `@key[p. 3]`；不要手写 `[1]` 之类的编号。
- 不确定的条目在 `references.bib` 上方加 `% UNVERIFIED: 原因`，并同步登记到
  `REVIEW.md` 与 `stats.unverified`。

## 7. 时效与证据分级

- 新领域优先 2025–2026 年工作；经典工作只作压缩背景。
- 每章至少一节讨论「最新进展与未解决问题」。
- 严格区分三档，并在正文显式标注：

| 标记 | 含义 |
| --- | --- |
| 【已有成果】 | 有文献支撑，给出引用 |
| 【本书推断】 | 作者的合理外推，说明依据 |
| 【本书提出】 | 本书的原创定义、协议或设计，声明未经社区检验 |

## 8. 风格

- 研究生教材口吻：连贯段落为主，列表为辅。
- 每个概念先直觉，再定义，再推导/例子。
- 代码块标注语言；代码必须来自可运行示例或明确标注为伪代码。
- 章末：一段小结 + `#keybox` 要点框。
- 中文标点用全角；中英文之间留空格；数字与单位之间留空格。

## 9. 生成声明

AI 参与写作的书，必须在 `PROVENANCE.md` 记录模型、日期、流水线、人工改动与
不可考项，并在 `NOTICE`、README 与发布站点保留 AI 生成标识。正文中不要假装
这些工作不存在——审读的人有权知道。
